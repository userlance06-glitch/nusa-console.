            Aturan token akses

            Ringkasan v1.1 · teks lengkap di docs/ATURAN-TOKEN.md

            Bentuk

            • Tepat 12 karakter.
            • Huruf besar, huruf kecil, angka, dan simbol ! @ # $ % ^ & * ( ) - _ = + ?.
            • Bersifat case-sensitive; tanpa spasi di tengah.
            • Dibangkitkan CSPRNG, tanpa pola atau tanggal.

            Penerbitan

            • Satu token aktif per pengguna.
            • Siklus rutin 1 tahun sekali.
            • Penerbitan baru mematikan token lama seketika.
            • Setiap penerbitan tercatat di audit tanpa nilai token.

            Penayangan

            • Ditampilkan satu kali saat diterbitkan.
            • Tidak ada menu “lihat token lagi”.
            • Jendela terkunci sampai pengguna mengonfirmasi sudah menyimpan.
            • Dilarang mengirim token lewat email/chat.

            Keamanan & pemulihan

            • Server menyimpan hash (Argon2id/bcrypt), bukan token.
            • 5 percobaan gagal → ditahan 60 detik.
            • Lupa token → tidak bisa masuk sampai jadwal tahunan berikutnya; tidak ada penerbitan ulang.
            • Masa berlaku pengganti mengikuti siklus tahunan, minimal 30 hari.

            Tombol Terbitkan ulang sekarang tersedia di layar masuk kapan pun token masih aktif — gunakan bila token hilang atau bocor.
